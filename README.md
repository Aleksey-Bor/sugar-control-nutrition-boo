## English

### About
This project is a self-contained interactive web book built from the guide **"Книга-памятка: Здоровое питание для контроля сахара"** (Healthy Eating for Sugar Control). It presents the full text as a single-page application (SPA) with smooth navigation, a clean reading experience, and a visual style inspired by fresh, healthy food.

### Features
- **Single HTML file** – no external dependencies, works completely offline.
- **SPA navigation** – pages are shown/hidden via a simple `goToPage()` function.
- **Responsive design** – adapts to mobile, tablet, and desktop screens.
- **Stylish UI** – green palette, traffic-light food lists, recipe cards, and soft animations.
- **Accessibility** – semantic markup, keyboard navigation (left/right arrow keys to move between chapters).
- **Full content** – all text from the original document is included without abbreviations.

### Technologies
- HTML5
- CSS3 (Flexbox, Grid, custom properties, animations, media queries)
- Vanilla JavaScript (ES5 compatible)

### How to Use
1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. Use the buttons or breadcrumbs to navigate. You can also use the **left/right arrow keys** to move between chapters.
